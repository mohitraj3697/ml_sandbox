# Daily ML Workbook
 
A personal repository documenting my day-to-day machine learning experiments, notes, implementations, and learnings. This is a living log — raw, consistent, and ongoing.
 
---
 
## About
 
This repo is where I push everything I work on related to machine learning. It covers concept explorations, algorithm implementations, paper readings, and hands-on experiments. No polish required — just showing up every day and putting in the work.
 
---
 
## What's Inside
 
Each day's folder contains whatever I worked on that day — notebooks, scripts, notes, or all three. Some days are deep dives into a single concept, others are broad explorations or project work.
 
Topics I work across include:
 
- Supervised and unsupervised learning
- Neural networks and deep learning
- Natural language processing
- Computer vision
- Model evaluation and optimization
- ML math — linear algebra, calculus, probability, statistics
---

 
## Tech Stack
 
- Python 3.x
- NumPy, Pandas, Matplotlib, Scikit-learn
- PyTorch / TensorFlow
- Jupyter Notebook
---
 
## Goals
 
- Build strong intuition for core ML algorithms before relying on libraries
- Work through at least one paper or chapter per week
- Push something every single day, no matter how small
- Periodically build end-to-end projects to consolidate learning
